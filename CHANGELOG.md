# Changelog
All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com), versioning: [SemVer](https://semver.org).

## [0.2.0] - 2026-10-24
### Added
- **App Debloater**: Clean detection and batch removal of Windows 11 bloatware and sponsored apps (Clipchamp, Cortana, News, Weather, Solitaire, TikTok, etc.) with recommended presets.
- **AI & Copilot Controls**: Disable Copilot, Windows Recall snapshots, Click-to-Do, and Edge AI sidebar.
- **Interface & Explorer**: Classic Windows 10 context menu, show file extensions, open Explorer to 'This PC', hide Task View & Chat icons, and taskbar 'End Task' option.
- **Privacy & Telemetry**: Disable Bing in Start Menu search, DiagTrack telemetry service, activity history, and silent store app downloads.
- **System Tools**: 1-click System Restore Point creation, Explorer process restart, and live diagnostic activity log viewer.
- **Redesigned Interactive UI**: Modern dark Fluent acrylic theme with navigation tabs, live search filtering, category pills, custom switch toggles, stats badges, and toast notifications.

## [0.1.0] - 2026-10-24
### Added
- Declarative tweak catalog (13 tweaks, EN/ES) and whitelist PowerShell engine with full undo.
- Timed modes with automatic restore (scheduled task).
- Experimental auto mode (game detector).
- Bilingual UI, risk levels with confirmation, auto-update via GitHub Releases.
